deckstrap

Set up a Steam Deck from a profile. Fresh installs of Decky Loader, its plugins, CSS themes and sound packs, Firefox with your extensions, GE-Proton, CryoUtilities and more, with your settings applied on top. One file, one click.

Download installer Jamie's Deck profile Bundle (.sh) for USB / offline

The first installer uses a sensible starter profile. The second applies Jamie's own setup: 11 Decky plugins, 36 CSS Loader themes with their exact patch choices, a CSS Loader profile and a sound pack, loaded from this profile pack. You can paste any profile pack URL into the installer's "Use a different profile" box.

How to run it

  1. On the Deck, hold the power button and choose Switch to Desktop.
  2. Open this page in the browser and click Download installer.
  3. Open the Downloads folder and double-click deckstrap.desktop. KDE asks whether to trust the file: choose Continue.
  4. The installer downloads, then opens full screen. Tick what you want, choose a sudo password (SteamOS has none by default), and watch it go. The screen is laid out for the Deck's display and touch.
  5. When it says Finished, tap Return to Gaming Mode.

Prefer a terminal? In Konsole: curl -fsSL https://raw.githubusercontent.com/jamieemb/deckstrap/main/install.sh | bash

What it sets up

  • Decky Loader, with plugins installed fresh from the Decky store (checksum verified) in your saved order, and each plugin's settings applied.
  • CSS Loader themes and Audio Loader packs fresh from the deckthemes store, with your enabled themes, patch choices and profiles restored.
  • Firefox from Flathub with extensions force-installed by policy (uBlock Origin by default), set as default browser.
  • GE-Proton, CryoUtilities recommended settings, daily Flatpak updates, SSH, Desktop Mode tweaks, optional Distrobox and EmuDeck.

Your own profile

A profile is one JSON file. Export yours from a Deck that is already set up the way you like, keep it anywhere, and build a bundle that carries it:

deckstrap export --name "My Deck" --out profile.json
./build.sh --profile profile.json --assets ./my-assets --out deckstrap.sh

Copy that one file to a USB stick and bash deckstrap.sh on the next clean install. Nothing from the old install is copied as code; the profile only records what to fetch and how to configure it.

Safe to re-run

Every step is idempotent. Run it again after a SteamOS update to get Decky back. Use bash deckstrap.sh --dry-run to see what would happen, and bash deckstrap.sh status to compare the Deck with the profile.
